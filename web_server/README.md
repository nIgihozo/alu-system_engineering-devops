## WEB-SERVER PROJECT!!

This project focuses on the foundational concepts of web servers, networking, and system automation using Bash scripting. The primary goal is to configure and manage a web server following specific requirements, emphasizing automation over manual intervention.

# Key Concepts & Learning Objectives

This project covers the following areas, which all team members are expected to understand and explain without external help:

General & Automation

Web Server Role: Understanding the main function of a web server (e.g., serving files, handling HTTP requests).

Concurrency: Understanding parent/child processes and why web servers utilize them for handling multiple requests.

Automation: Developing robust, non-interactive Bash scripts to configure servers, embodying the "lazy Software Engineer" principle for managing hundreds of servers.

# HTTP & Networking

HTTP Requests: Identifying and explaining the main HTTP request methods (GET, POST, etc.).

DNS: Understanding what DNS stands for, its main role (translating domain names to IP addresses), and common record types (A, CNAME, TXT, MX).

# Requirements

All tasks must be automated via Bash scripts.

Scripts must be executable and start with #!/usr/bin/env bash.

All scripts must pass Shellcheck validation.

Environment: Ubuntu
